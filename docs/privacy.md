# 隐私、数据生命周期与导出 / 删除

AI 聊天里的片段、提示词和思路可能包含个人事项、未发表想法或工作内容。本项目在实现前就把数据如何进来、如何出去写清楚。本文是设计原则，不是法律意见，也不声称已经符合某一法域的全部义务。

需求见 [requirements.md](requirements.md)，候选存放形态见 [architecture.md](architecture.md)。

## 本阶段的硬限制

- **决定**：立项文档和本仓库不得写入真实私密聊天、真实提示词或真实对话截录。举例必须是虚构的、无识别性的占位描述。
- **决定**：本轮不上传真实私密聊天到外部服务，不创建需要把用户对话交出去的集成。
- 当前仓库里只有立项说明，没有用户数据存储，也没有遥测。

## 设计时参考的原则

整理生命周期时，参考《通用数据保护条例》第 5 条中的目的限制、数据最小化、准确性、存储期限、完整性与保密等原则。正式文本见 [EUR-Lex：Regulation (EU) 2016/679](https://eur-lex.europa.eu/eli/reg/2016/679/oj)，条文转载见 [Art. 5 GDPR](https://gdpr-info.eu/art-5-gdpr/)。读取日期：2026-11-10。

这些原则在此只用来提醒：只为「收集、归档、回顾、复用用户自己选中的片段」而处理数据；能少存就少存；原文要保持准确；用户应能导出和删除；存放与传输要能防止无意泄露。它们**不是**「本项目已做 GDPR 合规」的证明，适用法律仍待日后按实际产品形态判断。

## 可能处理的数据（概念上）

实现之后，一条用户主动保存的记录可能包含：

- 选中的原文（聊天回答、提示词或思路）。
- 对应的原问题（若能取得）。
- 出处：产品名称、会话标识或链接、保存时间。
- 用户后来自愿添加的标题、标签或笔记。

MVP 建议不自动保存整段会话、不采集未选中的相邻消息、不采集账号密码、不采集与片段无关的浏览历史。若日后「自动暂存」被单独批准，需要重新写明多存了什么、保留多久、如何关闭和删除。

## 生命周期

### 1. 收集

- 建议的默认方式：用户选中片段后，明确执行一次保存。
- 能取到原问题和出处就一起保存；取不到就标记缺失，不编造。
- 不在用户未同意时，把原文发送到本机归档以外的地方。

### 2. 存储

- 2026-11-11 已拍板默认本机存放：片段与本地分词索引统一存于 macOS 本机 `Application Support/CodingRewind/stash.sqlite3`（开启 WAL 与 `secure_delete = ON`），场景 C 成文草稿存为用户可读的普通本地 `.md` 文件。
- **建议**：默认本地存放，不为保存功能强制注册账号或云同步。若以后提供可选同步或辅助检索，必须先说明数据会到哪里，并允许用户关闭。
- 用户注释与原文应可分辨，避免日后无法判断哪一句是当时的聊天、哪一句是后来写的。

### 3. 使用

- 用途限于用户回顾、查找和复用自己保存的片段。
- 自然语言找回若需要借助外部模型或服务，属于待决事项；未决之前，不得把原文作为默认出站数据。
- 不得把用户片段用于未声明的训练、分析或分享。

### 4. 导出

实现后应支持用户把自己的数据带出本工具，建议满足：

- 能导出全部记录，也能导出选中的若干条。
- 导出结果可独立阅读，至少包含原文、原问题（或缺失说明）、出处和保存时间；若有可选标题、标签、笔记，一并带上并与原文区分。
- 导出过程不经过未说明的第三方，除非用户当时明确选择了某种外部目标。

具体文件格式未定，不在本稿锁定。

### 5. 删除

实现后应支持：

- 删除单条记录。
- 删除全部由本工具保存的数据，并让用户能确认删除已完成。
- 若存在派生索引或缓存（例如为了检索），删除原文时也应删除或重建这些派生数据，避免「列表空了但原文还在索引里」。

浏览器扩展若使用浏览器自带存储，还应在文档中说明：卸载扩展或清理浏览器数据可能导致数据一并消失，因此导出不是可有可无的功能。rewind-for-x 的「可一键清空」是这类能力的一个公开例子，但本项目还需要单条删除，而不仅是全部清空。

### 6. 留存期限

默认建议：用户未删除的记录一直保留，因为这正是归档目的。不建议为了「自动减负」在用户不知情时删掉旧片段。若因存储上限必须淘汰（rewind-for-x 有 3000 条上限这一做法），只有在用户知情并可导出的前提下才能考虑，且目前**不是已定功能**。

## 本仓库自身

- 不保存真实用户聊天。
- 不在示例里使用可识别的真名、真实项目机密或真实对话。
- 以后若做演示数据，必须是虚构材料，并在文件中标明是示例。
