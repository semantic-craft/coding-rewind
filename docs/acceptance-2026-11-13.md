## 快捷键、剪贴板与数据生命周期最终补验

Chrome 快捷键由用户实际按键，Agent 随后查询 Memos。两次均新增 PRIVATE 测试记录，原文与当次原生窗口可访问性读出的选区一致。用户当次选区没有末尾换行，未以测试文件的末尾换行代替选区内容。

剪贴板验证以 `[[type: Data]]` 保存有序 item，逐项比较全部类型集合和原始字节。夹具包含两条 item，覆盖文本、HTML、RTF、PNG 和自定义二进制；macOS 自动增加 UTF-16 文本后共有七种格式表示。首次夹具检查拒绝了新增格式并恢复原剪贴板，随后改为校验所有指定格式并把系统新增格式一起纳入实际快照。成功捕获后快照相同，changeCount 增量为 0，说明走 AX 路径。两次空选区回退后快照也相同，changeCount 各增加 1，证明还原代码实际运行。测试进程只在内存中保留用户原剪贴板，结束后恢复并读回一致。

该结果覆盖本轮多格式夹具，不能宣称任意延迟提供数据的剪贴板类型都已验证。成功复制回退后来完成受控来源实测，见“成功复制回退补验”节。

## 原生网页全账户导出补验

用户完成网页登录后，从 Memos 设置的 Export & Import 页面点击 Export memos，浏览器实际下载 Memos Export Format ZIP。导出前通过 MCP 分页读取 NORMAL、ARCHIVED 主记录及各自评论，建立本地核对快照。压缩包含 25 份 Markdown 和 25 份 JSON，以及 manifest；其中主记录 14 条，评论 11 条。ZIP CRC 校验通过，记录编号集合、每份正文的 UTF-8 字节、state、visibility、createTime、updateTime、pinned 和评论的 parent 与快照一致。

manifest 显示附件数为 0，因此本轮不证明附件文件导出。全账户 ZIP、私密核对快照、截图和可重跑比较程序仅留在本机，未提交公开仓库。此项没有删除任何账户数据，也未修改产品代码。本机证据目录为 `.scratch/fallback-export/`。

## 成功复制回退补验

受控 AppKit 来源使用 NSTextView，仅把 AXSelectedText 返回值设为 nil，保留系统原生选区和复制行为。外部 AX 探针在捕获前后对同一进程读取，focused element 成功，selected text 返回无值（-25212）。自动化无法保持测试窗口为系统前台，最终由用户打开窗口并实际按全局快捷键，已安装日常应用执行捕获。来源记录收到一次 Command+C keyDown，keyCode 为 8，剪贴板计数增加；服务端随后出现 PRIVATE、source/macos、ready 新记录。

测试文件含末尾换行，共 88 个 UTF-16 单元，但用户当次实际选区范围为 location 0、length 87，不含末尾换行。复制回执与整份文件的比较因此为 false；服务端原文与外部读取范围对应的实际选区逐字一致。此项不宣称该次选中了末尾换行。

捕获前放入两条 item、七种实际格式表示，捕获后先比较全部类型集合及原始字节，再由验收工具恢复用户原剪贴板。结果全部相同，changeCount 增量为 2，原剪贴板恢复读回也一致。测试来源进程已结束。本轮验证了真实交付包的成功复制回退分支，没有为产品加入强制回退开关；受控来源不能代替任意第三方应用兼容性验收。
